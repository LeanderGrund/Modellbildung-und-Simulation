# Frühere Auswertungsläufe

Diese selbstständigen MAT-Dateien wurden bei der Umstellung auf die aktuelle
Studie aufbewahrt. Sie gehören nicht zur aktuellen Auswertung und nicht zu
`laufverzeichnis.csv`:

- `haltezeit_*.mat`: frühere Untersuchung mit einheitlichen Stationshalten.
- `zugzahl_04.mat`, `zugzahl_08.mat`: frühere Zugzahlfälle unter N=12.

Die aktuelle Haltezeitstudie verwendet das unveränderte GTFS-Profil mit
Zuschlägen von 0, 6, 12, 18, 24 und 30 Sekunden je Station. Ihre vollständigen
Rohdaten stehen unter `ergebnisse/laeufe/gtfs_plus_*.mat`.
